-------------------------------------------------------------

1. O que é um tema no WordPres?
Um tema é responsável pela aparência visual do site, definindo elementos como cores, fontes, organizaçãoe estilo das páginas.

2. O que é um plugin? Dê dois exemplos.
Um plugin é uma extensão que adiciona funcionalidades ao WordPress. Dois exemplos são:
- Plugin de formulário de contato: permite que visitantes enviem mensagens pelo site.
- Plugin de SEO: ajuda a otimizar o conteúdo para mecanismos de busca, como o Google.

3. Qual é a diferença entre página e post?
Uma página é usada para conteúdos mais estáticos, como “Sobre Mim” e “Contato”. Um post é uma publicação, geralmente 
organizada por data, como notícias, artigos e novidades de um blog.

4. O WordPress é gratuito? Explique.
O software WordPress disponível no WordPress.org é gratuito e de código aberto. Porém, para publicar um site usando
essa versão, normalmente é necessário contratar hospedagem e, em alguns casos, comprar um domínio. Já o WordPress.com 
oferece um plano gratuito com limitações e opções de planos pagos.
